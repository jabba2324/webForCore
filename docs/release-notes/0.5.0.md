## What's new in 0.5.0

Fixes from the smoke test's third round (#32), found migrating MVCForum, aspnet-mvc5-starter, Subtext, FunnelWeb and
mojoPortal.

### Fixes

- **`configSource` files in a subfolder load on Linux** (#26). `configSource="Config\settings.config"` was a
  Configuration Error on every request.
- **`relaxedUrlToFileSystemMapping="true"` no longer breaks `MapPath`** (#27). Every mapped path was
  `NOT_A_VALID_FILESYSTEM_PATH` on Linux.
- **`webForCore.Web.Mvc` brings `webForCore.Web.Helpers`** (#28), as `Microsoft.AspNet.Mvc` brought System.Web.Helpers.
  MVC 5 web.configs list it.
- **System.Web.Services.Description types compile in application code** (#34). `WsiProfiles` and `SoapBindingUse`
  (generic handlers, Web Reference proxies) were CS0433.
- **.NET Framework libraries see the application's SqlClient types** (#35). Types a .NET facade forwards to an assembly
  the application deploys (System.Data's SqlClient, System.Drawing, ...) were a second copy, and calls between such a
  library and the application failed with MissingMethodException.

### Migration guide (MIGRATING.md)

- A library's own `MembershipUser` can be ambiguous with System.Web.ApplicationServices' (#29).
- More versions webForCore requires: Humanizer.Core 2.14.1; System.Configuration.ConfigurationManager and
  System.Runtime.Caching come with webForCore (#30).
- A package's .NET Standard build can have less than its `net45` build (WindowsAzure.Storage, Hangfire 1.6) (#31).
- A `.resx` with non-string resources needs System.Resources.Extensions (#36).
- Remove `<compilation><assemblies>` entries for assemblies .NET doesn't have (System.Design, System.Data.Linq) (#37).
- WebActivator 1.x's start methods don't run either: call them from `Application_Start`, as for WebActivatorEx (#38).
- SDK-style project references are transitive: NU1605 and CS0118 (#39).

### Known issue

- `Assembly.Load("App_GlobalResources")` and `Assembly.Load("App_Code")` don't work (#33). With
  `<compilation optimizeCompilations="true">`, mojoPortal works.
